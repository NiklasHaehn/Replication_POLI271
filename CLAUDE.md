# Project Instructions

## Authorship & Attribution

- **Never** add `Co-Authored-By`, `Co-authored-by`, or any similar trailer to commit messages
- **Never** mention Claude, AI assistance, or any LLM tool in commit messages, PR titles, PR bodies, code comments, or any written output associated with this repository
- This applies to all commits, pull requests, issues, and documentation

## Commit Style

- Write concise, descriptive commit messages in English
- Focus on *what* changed and *why*, not *how*
- Never include tool attribution of any kind
